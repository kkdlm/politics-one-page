# 政治一页纸（完整版）· v2.29.4

考研政治选择题的背诵单页，自己做复习用的。浏览器打开 `index.html` 就能看，不用装东西；手机上「添加到主屏幕」后可当网页 App，断网也能用。

在线打开：https://kkdlm.github.io/politics-one-page/

## 内容

- 100 个考点，分九块：史纲 26 / 政经 17 / 建国后 14 / 马原 13 / 重要专题 10 / 资本主义及垄断 6 / 其他 6 / 三大辨析 4 / 会议大观 4。
- 题库 **596 道题（真题 140 + 模拟 192 + 肖八 264）**。
- 另有抽背、挖空、帽子题、会议时间轴、口诀。
- 卡片点开读正文，右上角打勾记「已掌握」，星号加收藏。
- 视觉：深朱 `#8E2723` + 暗金 `#B08A45`，「政」字圆印，金线圈启动屏。

内容照《2027 这就是一页纸·知识点手册》整理的，只给自己复习用，不卖也不往外传。原作者要是觉得不合适，说一声我就删掉。
